# gexf-cpp
Dado um grafo não dirigido de entrada, calcular algumas estatísticas usando algoritmos apresentados.

## Instalação

Instale a dependência com:

```bash
sudo apt install libpugixml-dev
```

# Disponivebilidade

[Github](https://github.com/batichotti/gexf-cpp)

## Uso

Compile o programa com:

```bash
make graph
```
